# 누락 관리형 마켓센싱 조사 운영 원칙

## 목적

마켓센싱 조사의 목표는 인터넷 전체를 읽는 것이 아니다. 중요한 외부 변화를 놓칠 수
있는 탐색 공간을 명시하고, 의사결정을 바꿀 가능성이 큰 빈칸에 조사 비용을 집중하며,
확인하지 못한 범위와 중단 이유를 재현 가능하게 남기는 것이다.

사용자가 단순히 `조사해`, `최근 변화 찾아봐`, `자료를 더 쌓아봐`라고 요청해도 이
운영 원칙을 기본 적용한다. 사용자가 조사 채널·기간·출처·비용을 명시적으로 제한하면
그 제한을 우선하되, 제한 때문에 남는 고위험 미확인 범위를 결과에 밝힌다.

완전성은 `인터넷 전체 확인`이라는 주장으로 표현하지 않는다. 다음 세 가지가 확인된
상태를 조사 완전성으로 본다.

1. 중요한 의사결정 영향 경로를 탐색 공간으로 표현했다.
2. 고위험 빈칸을 우선 확인하고 결론을 바꿀 후보를 원문으로 검증했다.
3. 미확인 범위, 접근 실패, 편중, 중단 조건과 다음 재탐색 트리거를 기록했다.

## 조사 단위: 커버리지 셀

URL이나 키워드 수가 아니라 다음 조합을 하나의 `coverage_cell`로 관리한다.

`사업축 × 영향 경로 × 변화 유형 × 지역·시장 × 시간 구간`

각 coverage cell은 `전제변경 패턴`을 보조축으로 가진다. 이 축은 URL 수를 늘리기 위한
분류가 아니라 익숙한 뉴스만 반복 수집하는 편향을 막는다.

- 대체수요: 다른 기술이 총수요가 아니라 특정 제품 수요를 제거하는가
- 시장접근 규칙: 세율 외의 데이터·원산지·인증이 판매자격을 가르는가
- 원료 병목: 최종 제품보다 희소한 투입재가 경쟁력을 가르는가
- 무역흐름 역전: 금지·제한 해제로 원료나 물량의 목적지가 바뀌는가
- 정책 결합: 별개 규제가 함께 적용될 때 제품 믹스나 채널 수익성이 바뀌는가
- 고객행동 간극: 전망과 달리 실제 계약·CAPEX·양산 일정이 먼저 움직이는가
- 원가구조 변화: 기술·정책이 비용 우위의 지배변수를 바꾸는가
- 시점 간극: 발표일과 효력·납품·손익 인식 시점이 의사결정 기한을 앞당기는가

각 셀의 후보에는 별도로 `signal_role`과 `signal_origin`을 붙인다. 이 두 값은 탐색축을
늘리기 위한 분류가 아니라 외부 변화와 자사 실행 소식을 섞지 않기 위한 출처 역할이다.
외부 시장·정책·경쟁사·거래상대 변화는 `core_market_signal`, 자사·자회사의 투자·증산·
계약·실적·공정 진척은 `execution_context`다.

- 사업축: 철강, 리튬, 에너지
- 영향 경로: 가격, 원가, 물량, 계약, 투자, 운영, 현금흐름 등 실제 사업 전달 경로
- 변화 유형: 정책·규제, 수급·가격, 경쟁사, 투자·프로젝트, 공급망·물류,
  고객·계약, 기술·운영, 재무·실적
- 지역·시장: 해당 조사에서 사업 영향 경로가 성립하는 국가, 권역, 거래 시장
- 시간 구간: 조사 기준일과 검색 시작·종료일. 마지막 성공 실행보다 설정된 겹침
  일수만큼 앞에서 다시 확인한다.

기술·국가·프로젝트 목록을 무한히 열거하지 않는다. 먼저 회사의 가격·원가·물량·계약·
투자·운영으로 전달되는 경로를 세우고, 이를 확인하는 데 필요한 대상만 탐색 셀에 넣는다.
영향 경로가 불명확한 일반 산업 동향은 우선순위를 낮추거나 제외한다.

## 네 단계 탐색

### 1. 발견

낮은 비용으로 후보를 넓게 찾는다. 기업 뉴스룸·IR·공시, 정부·규제기관·인허가,
거래소, 산업단체의 RSS·API·사이트맵·목록·공개 원문을 우선한다. 이 단계에서는 제목,
발행자, 게시일, canonical URL, 예상 coverage cell과 신규성만 판정하며 Claim을 만들지
않는다.

대상 회사 뉴스룸·IR의 높은 검색 노출을 시장 변화의 높은 중요도로 오인하지 않는다.
회사명을 언급하지 않아도 가격·수급·정책·경쟁사·고객·물류에서 회사로 이어지는 영향
경로가 명확한 후보를 우선 수집한다. 회사 발표는 노출 규모와 실행 상태를 확인하는
맥락 후보로 별도 보관한다.

발견 쿼리는 회사명 결합형만 쓰지 않는다. `대체기술 + 상용 계약/납품`, `원료 + 수입
재개/품질 기준`, `시장접근 + 데이터/인증`, `정책 A + 정책 B + 제품 믹스`, `전망 + 실제
구매계약`처럼 전제를 깨는 행동을 먼저 찾고, 그 뒤 회사의 노출을 연결한다.

### 2. 커버리지 점검

후보를 coverage cell에 배치하고 다음을 찾는다.

- 아직 확인하지 않은 고영향 셀
- 최근 확인이 오래된 셀
- 특정 언어·지역·발행자에 치우친 셀
- 공식 발표만 있고 물리적 이행 자료가 없는 셀
- 성공 자료만 있고 연기·중단·비용·허가 실패 신호가 없는 셀
- `execution_context`가 30%를 넘거나 특정 프로젝트·설비가 과반인 사업축

결과가 많은 셀을 더 검색하는 대신 중요한 빈칸으로 다음 예산을 이동한다.
신규 run의 사업축별 발행 후보는 `core_market_signal` 70% 이상을 완료 조건으로 삼는다.
단, 숫자를 맞추려고 영향 경로가 약한 일반 뉴스를 채우지 말고 미달 사유를 고위험
빈칸과 다음 트리거로 남긴다.

### 3. 검증

사업 판단을 바꿀 가능성이 있는 후보만 본문을 읽고 Source·Claim으로 등록한다.
중요한 결론은 가능한 한 독립된 출처 두 개 또는 1차 자료 한 개와 별도 검증 자료로
확인한다. 동일 보도자료의 재인용은 독립 발견 채널로 세지 않는다.

### 4. 반증 탐색

고영향 후보에는 최소 한 번의 반대 방향 탐색을 수행한다.

- 발표와 실제 생산·출하·집행 상태가 다른가
- 발표일과 효력일 또는 손익 인식 시점이 다른가
- 경영진 발언과 CAPEX·물량·계약 행동이 다른가
- 공식 후속 수치가 최초 보도나 시장 통념과 충돌하는가
- 연기, 중단, 취소, 자금 철회, 허가 거절, 비용 초과가 있는가

반대 근거가 없으면 `현재 확인된 반대 근거 없음`으로 기록한다. 결론을 흥미롭게 만들기
위해 반대 근거를 추정하지 않는다.

구조적 전환 후보는 한 번의 기사 급증으로 확정하지 않는다. 공공 통계·전망, 고객·경쟁사
실제 투자행동, 기술·원료 선호의 물리적 연결, 가격·점유율 시계열 중 둘 이상의 독립
채널이 같은 방향을 가리킬 때 Trend 후보로 올린다. 총시장 성장, 지역별 예외, 대체 기술의
성능 우위처럼 결론을 약화시키는 근거도 별도로 검색한다.

## 적응형 조사 예산

LLM 호출 횟수나 검색 결과 수를 모든 조사에 동일하게 고정하지 않는다. 각 coverage
cell의 상대적 우선순위를 다음 요인으로 판단한다.

`잠재 사업영향 × 긴급성 × 불확실성 × 미확인 경과 × 변화 가능성 ÷ 예상 조사비용`

정밀한 수식이나 허위 정량 점수는 필수가 아니다. `high`, `medium`, `low`와 판단 근거로
충분하다. 다음 상황에서는 조사 예산을 늘린다.

- 잠재 사업영향 또는 긴급도가 4~5점인데 독립 검증이 없다.
- 수치·일정·효력일·이행 상태가 출처 사이에서 충돌한다.
- 고위험 coverage cell이 미확인 상태다.
- 현지어·정부·고객·공급망 등 독립 탐지 채널이 비어 있다.
- 신규 정보가 기존 결론이나 대응 시한을 바꿀 가능성이 있다.

다음 상황에서는 예산을 줄이거나 탐색 가지를 닫는다.

- 신규 결과가 동일 원문의 재인용 또는 이미 등록된 본문이다.
- 영향 경로가 없거나 사업 판단을 바꿀 가능성이 낮다.
- 반복 쿼리에서 독립된 신규 원문과 결론 변경 정보가 나오지 않는다.
- 접근 통제 때문에 더 진행할 수 없고 공개 대체 출처도 확인했다.

## 중단 조건

고정 검색 횟수만으로 완료를 선언하지 않는다. 다음 조건이 충족되면 해당 탐색 가지를
중단할 수 있다.

- 최근의 서로 다른 3개 탐색 시도에서 신규 고영향 후보가 없다.
- 신규 독립 1차 출처 또는 결론을 바꾸는 Claim이 없다.
- 미확인 고위험 coverage cell이 없거나, 남은 셀의 미확인 이유와 후속 트리거가 있다.
- 공식 발표, 독립 검증, 실패 신호 중 해당 사건에 적용 가능한 채널을 확인했다.

검색되지 않았다는 사실을 사건이 없다는 증거로 사용하지 않는다. 기간·출처·언어·접근
제한 때문에 확인할 수 없으면 `unknown` 또는 `blocked`로 남긴다.

## 독립 탐지 채널

같은 검색엔진에서 문구만 바꾼 결과를 서로 독립된 확인으로 보지 않는다. 조사 주제에
적용 가능한 다음 채널 중 둘 이상을 확인한다.

- 기업 행동: 뉴스룸, IR, 공시, CAPEX·가이던스
- 정부 행동: 법령, 관보, 규제기관, 무역구제, 인허가
- 물리적 행동: 생산, 출하, 항만, 재고, 가격, 가동 자료
- 거래 상대 행동: 고객 조달, 경쟁사 계약, 공급사 증설
- 실패 신호: 연기, 취소, 자금 철회, 허가 거절, 비용 초과
- 후속 이행: 발표 후 30·60·90일 실제 이행
- 현지 자료: 영향 지역의 현지어 공식 자료

모든 사건에 모든 채널을 억지로 적용하지 않는다. 적용하지 않은 채널은 이유를 남긴다.
기업 행동 채널에서 대상 회사·자회사의 발표만 확인된 경우 독립 외부 채널로 세지 않는다.
경쟁사·고객·거래상대의 공식 발표는 `competitor_counterparty` 외부 발생원으로 분리한다.

## run 기록 계약

저장형 조사에서는 `.system/runs/<run-id>.json`에 기존 쿼리·결과·접근 실패와 함께 다음
내용을 기록한다. 기존 run 스키마가 자유 형식이면 `coverage` 객체 안에 둔다.

```json
{
  "coverage": {
    "scope": {
      "business_axes": ["철강"],
      "impact_paths": ["가격", "물량", "계약"],
      "signal_types": ["정책·규제", "수급·가격"],
      "markets": ["인도"],
      "date_from": "YYYY-MM-DD",
      "date_to": "YYYY-MM-DD"
    },
    "cells_checked": [],
    "high_risk_gaps": [],
    "channel_coverage": [],
    "query_yield": [],
    "stop_reason": "",
    "next_triggers": [],
    "limitations": [],
    "signal_mix": {
      "minimum_core_market_ratio": 0.7,
      "counts_by_axis": {},
      "dominant_asset_by_axis": {}
    }
  }
}
```

`cells_checked`에는 셀별 마지막 확인일, 확인 채널, 결과 상태를 남긴다. `query_yield`에는
쿼리별 신규 후보, 독립 원문, 신규 Claim, 결론 변경 정보의 수를 남겨 수확 체감을 판단할
수 있게 한다. 값이 없으면 빈칸으로 숨기지 말고 이유를 기록한다.

## 완료 판단과 보고

조사 완료 시 최소한 다음을 설명할 수 있어야 한다.

- 어떤 사업 의사결정 공간을 확인했는가
- 어느 독립 채널에서 무엇을 확인했는가
- 어느 고위험 빈칸을 해소했는가
- 무엇이 여전히 미확인이고 왜 그런가
- 왜 추가 탐색의 정보가치가 낮다고 판단했는가
- 어떤 사건이나 날짜가 재탐색을 발생시키는가

`전체 인터넷 조사 완료`, `관련 자료를 모두 확인`처럼 검증할 수 없는 표현을 쓰지 않는다.
대신 조사 기간, 확인 채널, 미확인 범위, 중단 근거를 함께 제시한다.

## 사후 누락 감사

월간 또는 분기 감사에서 뒤늦게 중요해진 사건을 표본으로 뽑아 최초 탐지 실패 원인을
다음 중 하나로 분류한다.

- 키워드·별칭 누락
- 출처·채널 누락
- 현지어·지역 누락
- 영향 경로 오분류
- 초기 우선순위 과소평가
- 접근 실패
- 발표 후 이행 추적 누락

실패 원인은 다음 실행의 coverage cell, 쿼리, 출처 목록 또는 재탐색 트리거에 반영한다.
과거 run과 Claim을 삭제하거나 결과를 사후에 성공으로 바꾸지 않는다.
