# 중국 일부 희토류 관련 품목 수출통제

## 원문 보존

- 원문: https://www.mofcom.gov.cn/cms_files/filemanager/policySummary/viewcore_a6ea0f03b9be475a9d06ee9d088d605d.html
- 접근 상태: Vercel 공개 배포의 보관 원문을 복구한 기록입니다.

### 보관된 원문 요약

중국 상무부와 해관총서가 2025년 4월 4일 시행한 희토류 관련 품목 수출통제의 공식 내용을 확인한 기록입니다.

- 사마륨, 가돌리늄, 터븀, 디스프로슘, 루테튬, 스칸듐, 이트륨 관련 금속·합금·산화물·화합물·표적재와 일부 영구자석 품목을 수출허가 대상으로 정했습니다.
- 수출자는 국무원 상무 주관부문에 허가를 신청하고 세관 신고에서 통제품목 여부와 두용도 품목 코드를 표시해야 합니다.
- 조치는 2025년 4월 4일부터 시행됐습니다.

이 기록은 2025년 10월의 추가 희토류·기술 통제와 구분합니다.
